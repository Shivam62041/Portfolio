# Shivam Kumar Jha - Personal Portfolio 🚀
**Software & Full Stack Developer**

Welcome to my personal portfolio repository! This project showcases my skills, experience, and featured projects as an MCA (AI & ML) graduate and full-stack developer.

## 🌐 Live Demo
Check out the live version of my portfolio here: **[https://shivam-portfolio-kohl.vercel.app](https://shivam-portfolio-kohl.vercel.app)**

## 🛠️ Built With
- **Frontend Framework:** React.js
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Hosting:** Vercel

## ✨ Key Features
- **Modern UI/UX:** Clean, dark-themed, glassmorphism design.
- **Fully Responsive:** Optimized for desktops, tablets, and mobile devices.
- **Smooth Animations:** Integrated with Framer Motion for scroll-triggered and interactive animations.
- **Dynamic Sections:** Includes Hero, About, Skills, Projects, Experience, Education, Certifications, and Contact.
- **Resume Integration:** A direct link to view and download my latest PDF resume.

## 💻 Getting Started Locally
To run this project on your local machine:
1. Clone the repository: `git clone https://github.com/Shivam62041/Portfolio.git`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Open your browser and navigate to the localhost URL provided.
